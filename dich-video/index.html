🔊 Giọng lồng tiếng

      
App dùng lần lượt theo thứ tự dưới đây: dịch vụ trên hết lượt/lỗi thì tự đọc lại cả video bằng dịch vụ kế tiếp. Mỗi dịch vụ chọn sẵn 1 giọng mặc định, bấm 🔊 để nghe thử.


      

        1. ElevenLabs 
        
        
        
        

          Cách lấy mã
          
    
            
  1. Đăng ký tại elevenlabs.io (gói trả phí: Subscription).
    2. 
            
  2. Vào API Keys → Create API Key → bật quyền Text to Speech, Voices → sao chép dán vào đây.
    3. 
          

        

        
        
        
        
        

          
          
        

        
Danh sách gồm giọng trong tài khoản và giọng Việt được dùng nhiều nhất trong thư viện ElevenLabs (🇻🇳). Chọn giọng thư viện thì app tự thêm vào tài khoản.

        

      


      

        2. Gemini 
        
        
        
        
Dán mã trả phí vào đây nếu muốn đọc không lo hết lượt (~600đ cho video 2 phút). Mã này chỉ dùng để đọc tiếng Việt; nghe & dịch vẫn dùng mã miễn phí ở trên.

        
        
        

          
        

        
Miễn phí ít lượt/ngày. Các câu sát nhau được gộp lại đọc 1 lần để đỡ tốn lượt.

      


      

        3. Fish Audio (miễn phí) 
        
        
        
        

          Cách lấy mã (miễn phí, không cần thẻ)
          
    
            
  1. Đăng ký tại fish.audio (đăng nhập bằng Google).
    2. 
            
  2. Vào API Keys → tạo mã → sao chép dán vào đây.
    3. 
          

        

        
        
        

          
          
        

        
Dùng bản S2.1 Pro Free (miễn phí, giới hạn "dùng hợp lý"). Danh sách là các giọng Việt được dùng nhiều nhất. Cần đăng nhập app PHAHA (đi qua máy chủ PHAHA).

      


      

        4. Microsoft Azure 
        
        
        
        
        
        

          Cách lấy mã
          
    
            
  1. Tạo tài khoản tại azure.microsoft.com/free (cần thẻ để xác minh).
    2. 
            
  2. Tạo dịch vụ Speech → Region Southeast Asia → Pricing tier Free F0 → Create.
    3. 
            
  3. Mở dịch vụ → Keys and Endpoint → sao chép KEY 1 và Location/Region.
    4. 
          

        

        
        
        

          
          
        

        
Gồm giọng Việt (Hoài My, Nam Minh) và các giọng "đa ngôn ngữ" đọc được tiếng Việt.

        

      


      

        5. Microsoft Edge (miễn phí) 
        
        
        
        

          
        

        
Giọng "Đọc to" của trình duyệt Edge: không cần mã, gần như không giới hạn. Không chính thức – Microsoft có thể chặn bất cứ lúc nào. Cần đăng nhập app PHAHA.

      


      

        Thêm: Google Cloud (không bắt buộc) 
        
        
        
        
        
        

          
          
        

        

      


      

        Cuối cùng: Giọng máy (luôn có)
        
Giọng nữ đọc tiếng Việt chạy ngay trên điện thoại – dùng khi mọi giọng trên đều không được. Lần đầu tải khoảng 90MB.

        

          
        

      


      

        🔁 Dự phòng khi Gemini hết lượt (miễn phí)
        
Gemini quá tải hoặc hết lượt thì app tự chuyển lần lượt: Groq → Cloudflare → Azure → OpenRouter. Dịch vụ nào chưa cài thì bỏ qua.


        
        
        
Vào console.groq.com/keys → đăng nhập Google → Create API Key → sao chép. Không cần thẻ.


        
        
        


        
        
        
        
        
Muốn Azure dịch: tạo thêm dịch vụ Translator (gói Free F0, 2 triệu ký tự/tháng) → Keys and Endpoint → dán KEY 1 và Location.


        
        
        
Vào openrouter.ai/settings/keys → Create Key → sao chép.
