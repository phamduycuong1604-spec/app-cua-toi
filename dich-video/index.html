Lời thoại

Bấm vào giờ để xem đoạn đó. Sửa câu tiếng Việt nếu chưa hay rồi bấm “Làm lại”.

⚙️ Cài đặt

Lấy miễn phí tại aistudio.google.com/apikey → Create API key → sao chép rồi dán vào đây. Mã chỉ lưu trên máy này.

Cách bật (làm 1 lần)
  1. Vào console.cloud.google.com/billing → gắn thẻ thanh toán (không trừ tiền nếu dùng trong mức miễn phí).
  2. Mở Cloud Text-to-Speech API → chọn đúng dự án của mã Gemini → bấm Enable.
  3. Quay lại đây, bấm Tải danh sách giọng.

Nhiều câu liền nhau được gộp vào 1 lần đọc để đỡ tốn lượt.
