Lời thoại

Bấm vào giờ để xem đoạn đó. Sửa câu tiếng Việt nếu chưa hay rồi bấm “Làm lại”.

⚙️ Cài đặt

Lấy miễn phí tại aistudio.google.com/apikey → Create API key → sao chép rồi dán vào đây. Mã chỉ lưu trên máy này.

Cách bật (làm 1 lần)
  1. Vào console.cloud.google.com/billing → gắn thẻ thanh toán (không trừ tiền nếu dùng trong mức miễn phí).
  2. Mở Cloud Text-to-Speech API → chọn đúng dự án của mã Gemini → bấm Enable.
  3. Quay lại đây, bấm Tải danh sách giọng.

Cách lấy mã (làm 1 lần)
  1. Tạo tài khoản miễn phí tại azure.microsoft.com/free (cần thẻ để xác minh).
  2. Vào tạo dịch vụ Speech → Region chọn Southeast Asia → Pricing tier chọn Free F0 → Review + create → Create.
  3. Mở dịch vụ vừa tạo → Keys and Endpoint → sao chép KEY 1 và Location/Region dán vào đây.

Cách lấy mã (làm 1 lần)
  1. Đăng ký miễn phí tại elevenlabs.io.
  2. Vào API Keys → Create API Key → bật quyền Text to Speech và Voices (Read) → sao chép mã dán vào đây.
  3. Muốn thêm giọng: vào Voice Library, lọc tiếng Việt, bấm Add rồi quay lại tải danh sách giọng.

Gói miễn phí không được dùng cho video kiếm tiền. Hết lượt thì app tự chuyển sang Google Cloud (nếu đã cài).

Nhiều câu liền nhau được gộp vào 1 lần đọc để đỡ tốn lượt.
